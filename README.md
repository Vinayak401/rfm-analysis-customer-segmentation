# RFM Analysis And Customer Segmentation

## Project Overview:-

An end-to-end Customer Analytics project using PostgreSQL and Power BI to analyze customer purchasing behavior, measure retention, and segment customers using RFM (Recency, Frequency, Monetary) analysis.

## Tools & Technologies:-

PostgreSQL
SQL
Power BI
DAX
Excel / CSV

## Project Objectives:-

Analyze customer purchasing behavior.
Identify repeat and inactive customers.
Calculate customer retention.
Perform RFM analysis using Recency, Frequency, and Monetary values.
Assign RFM scores and create customer segments.
Identify high-value customers and potential churn risks.
Develop actionable business recommendations.

## SQL Analysis:-

Data cleaning and preparation.
Customer purchase analysis.
Repeat customer analysis.
Customer retention analysis.
RFM scoring using SQL window functions.
Customer segmentation.

## RFM Methodology:-

Recency: How recently a customer made a purchase.
Frequency: How frequently a customer purchased.
Monetary: How much a customer spent.
Customers were scored and segmented based on their RFM metrics.

## Power BI Dashboard:-

Developed interactive dashboards to explore customer segments, purchasing patterns, and customer performance.

## Business Insights & Recommendations:-

Identify high-value customers for targeted loyalty campaigns.
Develop retention strategies for at-risk customers.
Identify customers with declining purchasing activity.
Design targeted marketing strategies for different customer segments.

## Project Structure:-

SQL: Data preparation and analytical queries.
PowerBI: Interactive customer analytics dashboard.
Dashboard_Screenshots: Dashboard previews.
